1) CLASS: CameraShakeManager (MonoBehaviour)
File: Assets/Scripts/CameraShakeManager.cs
Ringkasan:
- Manager singleton untuk efek kamera shake saat player menerima damage.

Field/Property penting:
- static CameraShakeManager instance: referensi singleton.
- PlayerHealth playerHealth: sumber event damage player.
- float globalShakeForce: besar gaya shake global.

Action/Event yang dipakai:
- Subscribe ke PlayerHealth.OnDamaged (event Action<float, float>) pada OnEnable.
- Unsubscribe dari PlayerHealth.OnDamaged pada OnDisable.

Fungsi:
- Awake(): set singleton instance, cari PlayerHealth jika belum di-assign.
- OnEnable(): mulai dengar event OnDamaged milik playerHealth.
- OnDisable(): berhenti dengar event OnDamaged.
- HandlePlayerDamaged(float current, float max): callback saat player kena damage, memicu shake.
- CameraShake(CinemachineImpulseSource impulseSource): panggil impulse dengan globalShakeForce.

10) CLASS: BossHealth (MonoBehaviour)
File: Assets/Scripts/Boss/BossHealth.cs
Ringkasan:
- Menyimpan HP boss dan menerima damage dari hitbox serangan player.

Field/Property penting:
- float currentHealth, maxHealth.
- float damageReceived: nilai damage terakhir dari event player attack.

Action/Event:
- event Action<bool> OnDied: broadcast boss mati.
- event Action<float, float> OnDamaged: broadcast HP terkini boss.
- Subscribe ke static event PlayerAttack.OnAttack (Action<float>) pada OnEnable.
- Unsubscribe dari PlayerAttack.OnAttack pada OnDisable.

Fungsi:
- OnEnable(): subscribe setDamageReceived ke PlayerAttack.OnAttack.
- OnDisable(): unsubscribe.
- Awake(): set currentHealth = maxHealth.
- takeDamage(float damage): kurangi HP, cek mati, invoke OnDamaged.
- checkDeath(): panggil die() jika HP <= 0.
- setDamageReceived(float damage): update damageReceived dari event attack player.
- die(): set HP ke 0, invoke OnDied(true), log boss defeated.
- OnTriggerEnter2D(Collider2D collision): jika kena tag PlayerAttackHitBox, terapkan takeDamage.

11) CLASS: BossMovement (MonoBehaviour)
File: Assets/Scripts/Boss/BossMovement.cs
Ringkasan:
- Menggerakkan boss ke target player, berhenti di jarak tertentu, dan mengatur flip arah.

Field/Property penting:

12) CLASS: BossStateController (MonoBehaviour)
File: Assets/Scripts/Boss/BossStateController.cs

- Mengatur phase boss dan pola serangan berbasis coroutine.

Field/Property penting:
- Durasi: basicAttackDuration, pattern2Duration, pattern3Duration.
- Damage: damageBasicAttack, damagePattern2, damagePattern3.

- Pattern2(): aktifkan event pattern2 + damage, tunggu durasi, lalu nonaktifkan.
- Pattern3(): aktifkan event pattern3 + damage, tunggu durasi, lalu nonaktifkan.
- ResetAllAttackState(): set semua event state attack ke false.

17) CLASS: PlayerMovement (MonoBehaviour, IMovementController, IDashController)
File: Assets/Scripts/Player/PlayerMovement.cs
Ringkasan:
- Controller gerak player: jalan, lompat, wall jump, dash, flip, ground check.

Field/Property penting:
- Movement: speed, dir, rb.
- Interface properties: MoveDirection, FacingRight, IsDashing.
- Jump: jumpForce, isGrounded, maxJump, currentJump.
- Facing: facingRight.
- Dash: dashSpeed, dashDuration, dashCooldown, isDashing, dashTimer, nextDashTime.
- Air control: groundAcceleration, airAcceleration.
- Wall movement: wallJumpForce, isTouchingWall, wallSide.
- Utility: originalGravityScale, canInput.

Action/Event:
- event Action<bool> OnJump.
- event Action<bool> OnWallJump.
- event Action<bool> DashStateChanged.
- event Action<bool> OnMoving.
- Subscribe ke PlayerWallCheck.WallContactChanged pada OnEnable.
- Unsubscribe pada OnDisable.

Fungsi:
- Awake(): cache Rigidbody2D, PlayerWallCheck, dan original gravity.
- OnEnable(): subscribe HandleWallContactChanged.
- OnDisable(): unsubscribe HandleWallContactChanged.
- Update(): update dash timer, input, jump, dan flip.
- FixedUpdate(): eksekusi movement physics.
- HandleInput(): baca input A/D dan shift untuk dash.
- HandleMovement(): movement horizontal dengan acceleration, invoke OnMoving.
- HandleJumpInput(): validasi input space, wall jump atau normal jump.
- CanWallJump(): cek syarat wall jump.
- PerformWallJump(): beri velocity wall jump, update state, invoke OnWallJump.
- Flip(): set orientasi sprite berdasarkan facingRight.
- HandleWallContactChanged(bool touchingWall, int side): update wall state dan gravity.
- StartDash(): aktifkan dash state, lock input, invoke DashStateChanged(true).
- DashTick(): jalankan dash movement, akhiri saat timer habis, invoke DashStateChanged(false).
- OnCollisionEnter2D(Collision2D collision): set grounded saat sentuh Platform.
- OnCollisionExit2D(Collision2D collision): unset grounded saat keluar Platform.

CATATAN UMUM ACTION/EVENT (RINGKAS)
- Event player ke boss:
  - PlayerAttack.OnAttack -> BossHealth.setDamageReceived
- Event boss ke player:
  - BossStateController.basicAttackDamage/pattern2Damage/pattern3Damage -> PlayerHealth.setDamageReceived
- Event health feedback:
  - PlayerHealth.OnDamaged -> CameraShakeManager + PlayerDamageFeedback + PlayerAnimationHandler
  - BossHealth.OnDamaged -> BossStateController
- Event attack animation:
  - BossStateController OnBasicAttack/OnPattern2/OnPattern3 -> BossAnimationController
  - BossAnimationController.isHandlingAttack -> BossMovement
- Event movement animation:
  - PlayerMovement.OnMoving/OnJump/OnWallJump + PlayerWallCheck.WallContactChanged -> PlayerAnimationHandler
  - PlayerAttack.AttackStateChanged -> PlayerAnimationHandler
